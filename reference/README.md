# Material de referência

Arquivos do artefato de design "Template de relatório coLAB" que não fazem parte do app.

Artefato: https://claude.ai/artifact/3KhM3b91rM36vXU7y5Q96a

## Conteúdo do artefato (pasta `project/`)

- `Relatorio de Conjuntura.dc.html` — template visual do relatório (depende do runtime do editor de design: `support.js`, `doc-page.js`, `image-slot.js`, `_ds/broadsheet-*`).
- `_ds/broadsheet-*/` — design system "broadsheet" (tokens, estilos, manifesto).
- `assets/` — logotipos do coLAB (PNG e SVG, versões preta e branca).
- `gdocs/coLAB-Analise-de-Conjuntura-07.docx` — relatório nº 07 usado como referência de conteúdo.
- `uploads/` — figuras de exemplo (análise de sentimentos, dendrograma, detecção de comunidades, nuvens de tags, imagens por cluster etc.).
- `shots/` — capturas de tela do ReportLAB.
- `reportlab/` — o app, idêntico ao que está na raiz deste repositório (conferido por SHA-256 em 2026-11-19).

Os arquivos binários (imagens, .docx) não puderam ser exportados automaticamente; baixe-os do artefato e coloque-os aqui se forem necessários.
